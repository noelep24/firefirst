# NERIS value sets

Choice lists ("value sets") from the NERIS Data Framework published by UL FSRI:
https://github.com/ulfsri/neris-framework (`core_schemas/value_sets/csv`, commit 60c2941, 2025-10-23).

They are copied unchanged so FireFirst offers exactly the codes NERIS accepts. When NERIS publishes a new
schema version, replace these files with the new ones and run the incident tests.
